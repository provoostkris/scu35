# SCU35 Repository

This repository contains some source files and related materials for the SCU35 demo board.

## Overview

The repository is organized as follows:

- `docs/` — documentation to help you get started with the demo kit
- `demo/` — a simple Vivado demonstration project to help you get up and running quickly

## Getting Started

1. Review the documentation in `docs/`.
2. Open the demo project in `demo/`.
3. Follow the setup and usage instructions in the project documentation.

## Notes

This project is intended as a starting point for exploring the SCU35 demo board and its capabilities.
More information on the board can be found here : https://www.amd.com/en/products/adaptive-socs-and-fpgas/evaluation-boards/scu35.html
